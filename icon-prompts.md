# Talent Forge — WoW icon prompts

Prompts for every node on your current Life Talent Tree (53), plus a few older nodes that were on the original board and are not in the tree anymore.

Each block is standalone. Paste **one block** into ChatGPT’s image generator. You do not need the master prompt if you use these, because the style rules are already inside every block.

Generate every icon at exactly **256×256 pixels**. That size stays sharp inside the circular nodes and stays small enough to deploy on Vercel. Do not generate 512, 1024, or larger.

When it looks right, save the 256×256 image, edit the node, and press **Open folder** to pick the file from Explorer. Do not type a folder path.

Style target: a Blizzard ability icon from about 2004–2010. One chunky painted object, centered, readable when it is tiny and cropped into a circle. No words in the picture.

---

## Master prompt

Use this if you want to write your own subject line instead of using the blocks below. Paste it once, then add `Subject:` and `Mood:` for the node.

```
Paint one World of Warcraft ability icon, Blizzard circa 2004–2010. Exactly 256×256 pixels. One hand-painted object, centered, so the picture crops cleanly into a circle. Thick brushwork, saturated color, dark smoky background, strong rim light, readable at 64 pixels. No text, letters, numbers, watermark, frame, or border. Not a photo, not anime, not a 3D render, not flat modern UI.

Subject: <one object>
Mood: <earned and bright | golden and not yet earned | moonlit and slightly worn | arcane purple and rare>
```

Mood key, matching the tree:

- **Done** — earned and bright
- **Goal** — golden and not yet earned
- **Used to** — moonlit and slightly worn
- **Special** — arcane purple and rare
- **Neutral** — plain steel, unmarked
